# Permitted to Build

Interactive housing-obligation dashboard from the October 21, 2026 Master Housing Ledger. Revised October 29, 2026.

The page retains all 34 records and the four original evidence filters. Click transfer connections to inspect their source records, search and filter the full ledger, or use the Relationships, Geography, In-lieu fees and Evidence tabs. Unknown values remain unknown. Updated November 11, 2026: The Refuge names Apollo, Flora + Fauna and Rowyn as research-identified senders, shown as Candidate map connections. Its 41 reported inbound units remain one aggregate with no per-sender split. Fourth & Palm's City-recorded Complete Communities on-site classification is reconciled to CPRA-0307.

The original workbook and an exact 34-record CSV export are in `docs/downloads`. Public source URLs appear only where supplied or verified; other sources are identified by their workbook references.

The current page package passed Chromium checks for loading, all nine flow selections, all tabs, all 34 ledger records, the four evidence filters, search, CSV export, source downloads and phone overflow. Results and desktop/phone screenshots are attached to the workflow run.

Publishing uses GitHub Pages' built-in branch deployment. In Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/docs**, then **Save**. This owner-controlled setting creates the site without asking the test workflow to administer Pages. Subsequent changes to `docs` publish automatically; browser checks also run on pushes.
